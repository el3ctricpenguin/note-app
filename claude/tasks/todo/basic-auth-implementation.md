## 実装詳細

### 環境変数形式
```
BASIC_AUTH_USERS={"admin":"admin-pass","viewer":"viewer-pass","dev":"dev-pass"}
```

### 想定フロー
1. ユーザーがサイトにアクセス
2. Basic認証チェック → 未認証なら401
3. Basic認証OK → 既存のJWT認証チェック
4. JWT未認証 → ログイン画面へリダイレクト
5. JWT認証OK → アプリケーション画面

## 注意点
- Basic認証は全てのリクエストに適用
- APIエンドポイントも含む
- 静的ファイル（_next等）は除外
